# IP监控2.0 · 网络连接监控（NetWatcher）

> 项目代号：**IP监控2.0**

一个在 Windows 上运行的**常驻后台**网络连接监控工具，图形化界面，记录电脑每次连接了哪些 IP、收发多少数据、连接了多久，并自动识别 IP 归属地（精确到城市）。

- **零依赖、零安装**：纯 C# 编写，用 Windows 自带的 .NET Framework 编译器编译成单个 `NetWatcher.exe`，双击即可运行。
- 数据按**日期**归档，可查看今天 / 昨天 / 前天或任意一天；旧版 1.0 的数据文件可以直接读取。
- **诚实标注**：普通权限下逐 IP 流量是「估算」，管理员权限下 EStats 可用才是「精确」，界面上明确区分。

> **2.0 的核心变化**：修正 1.0「EStats 失败被静默吞掉、仍无条件标记 `precise=true`（谎报精确）」的问题——2.0 按 EStats 的实际返回值判断，失败会写日志并在界面诚实降级为「估算」；采样从 60 秒缩短到 5 秒；界面重排（四个标签页可见、列头排序、搜索、新 IP 标记）；数据改为原子写盘；区分「真实会话数」与「采样次数」。**注意：精确模式能否生效取决于本机 EStats 是否可用，不是 2.0 保证一定可用。**

## 一、功能特性

| 功能 | 说明 |
|------|------|
| 连接记录 | 定时（默认 5 秒）扫描 TCP 连接（IPv4 + IPv6），记录远端 IP、端口、进程名、进程路径、PID、连接状态 |
| 实时视图 | 每 1 秒刷新：整机上下行速度、今日累计；上表按 IP 汇总，下表列出每条连接的明细 |
| 进程视图 | 资源监视器式**树形图**：应用程序 → PID → 远端 IP（含端口/协议/字节），按活跃度排序；支持双击 IP 行筛选 |
| 流量统计 | 每个 IP / 每个进程的累计下载、上传字节、平均速率、峰值速率 |
| 精确 / 估算标注 | 管理员且 EStats 可用时逐 IP 字节为**精确**，否则按连接数均分为**估算**，界面分别标注 |
| 连接时长与会话 | 每个 IP 的累计连接时长、**真实会话数**（由「无连接」变「有连接」的次数）、首次/最近连接时间 |
| 进程信息 | 进程名、完整路径、PID、进程启动时间（避免 PID 复用被合并统计） |
| IP 归属地 | 识别到**城市**级（国家 + 省市 + 城市 + 运营商），后台异步解析并本地缓存，不阻塞界面 |
| 总流量 | 整机累计上行/下行字节、实时上下行速率、当日峰值；统计时排除 Loopback / Tunnel 网卡，与逐 IP 口径一致 |
| 新 IP 标记 | 当天首次出现的公网 IP 用 `NEW` 标记/颜色提示，可选托盘气泡提醒 |
| 排序与复制 | 点击列头切换升/降序（刷新后保持）；表格行可 `Ctrl+C` 或右键复制 |
| 按日查看 | 今天 / 昨天 / 前天 + 日历选择任意日期；顶部搜索框按 IP / 进程 / 城市 / 域名过滤 |
| 历史概览 | 各日期的总流量、峰值、IP 数、采样次数汇总对比 |
| 导出 CSV | 把某一天的统计导出为 CSV（Excel 可直接打开） |
| 数据可靠性 | 每日 JSON **原子写盘**（先写临时文件再替换），最多保留每分钟一条采样曲线（1440 条/天） |
| 兼容旧数据 | 能读取 1.0 的 `data\*.json`（缺失字段取默认值），升级不丢历史 |
| 后台常驻 | 关闭窗口最小化到系统托盘，监控继续运行；单实例，重复启动会提示 |
| 开机自启 | 写入 HKCU 启动项，登录后在后台运行（不需要管理员） |

## 二、使用方法

### 2.1 启动

- 双击 `bin\NetWatcher.exe`，或双击桌面快捷方式「IP监控」；
- 也可以运行仓库里的安装脚本（见 2.6），安装脚本会创建桌面快捷方式并注册开机自启。

启动后主窗口顶部依次是：标题、**运行模式**（精确/估算，带颜色）、最近扫描时间、扫描间隔。

日期行：`今天 / 昨天 / 前天` 三个按钮 + 日历选择框 + **搜索框**（输入 IP、进程名、城市或域名过滤）+ 刷新按钮。

### 2.2 四个标签页

| 标签页 | 内容 |
|--------|------|
| **实时连接** | 顶部 4 个统计（↓速度 / ↑速度 / 今日↓ / 今日↑）；上表按 IP 汇总（IP、城市/地区、运营商、连接数、↓速度、↑速度、标记）；下表是连接明细（IP、地址、应用程序、PID、端口、协议、上传、下载、总流量、时长、标记） |
| **进程视图** | 树形「应用程序 → PID → 远端 IP:端口(协议)」，每个节点显示收发字节与连接次数；同一进程的不同启动实例按 PID + 启动时间区分；双击某个 IP 行可跳回筛选结果 |
| **按日统计** | 所选日期的逐 IP 明细：城市、运营商、连接时长、会话数、下载/上传字节、平均/峰值速率、是否精确 |
| **历史概览** | 各日期的总流量、峰值、IP 数、采样次数对比 |

### 2.3 排序、复制、筛选

- 点击任意表格的**列头**排序，再次点击切换升/降序；切换标签页或刷新后排序方式保持。
- 选中行按 `Ctrl+C`，或右键菜单「复制」，把整行文本复制到剪贴板。
- 顶部搜索框的内容会同时过滤表格；清空后恢复。

### 2.4 托盘与关闭窗口

- 关闭主窗口 = **最小化到系统托盘**（右下角图标），监控继续。
- 托盘图标右键：显示主窗口 / 刷新 / 退出。
- 当天首次出现新的公网 IP 时，可弹出托盘气泡提醒（设置里可关）。

### 2.5 设置

点击底部「设置」可修改：

| 设置项 | 说明 |
|--------|------|
| 扫描间隔 | 2 / 5 / 10 / 30 / 60 秒，默认 5 秒（越短越精细，占用略高） |
| 开机自动启动 | 等价于 `--autostart-on/off`，写 HKCU 启动项 |
| 数据保留天数 | 0 = 永久保留；大于 0 时自动清理超过天数的旧数据 |
| IP 归属地识别 | 关闭后不再联网查询城市信息 |
| 新 IP 提示 | 新公网 IP 首次出现时是否弹托盘气泡 |
| 显示本机/内网 IP | 是否在列表中显示 127.x / 10.x / 192.168.x 等本地地址 |
| 启动时最小化 | 开机自启时只驻留托盘 |

底部还有：**导出CSV**、**打开数据目录**、**以管理员身份重启**（用于切换到精确模式）。

### 2.6 安装与卸载（可选）

仓库根目录提供两个 PowerShell 脚本（Windows 自带组件，无需安装任何东西）：

```powershell
# 安装：创建数据目录 + 注册开机自启 + 桌面「IP监控」快捷方式
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1

# 可选参数
#   -NoShortcut            不创建桌面快捷方式
#   -DataDir "D:\NetWatcherData"   使用自定义数据目录

# 卸载：结束进程 + 删除开机自启 + 删除桌面快捷方式（默认保留数据）
powershell -NoProfile -ExecutionPolicy Bypass -File uninstall.ps1

# 连同数据一起删除（谨慎！）
powershell -NoProfile -ExecutionPolicy Bypass -File uninstall.ps1 -DeleteData
```

两个脚本都可以**重复执行**（幂等）；安装/卸载都不需要管理员权限。

- 安装时：会创建桌面「IP监控」快捷方式，并**删除 1.0 遗留的同程序快捷方式「NetWatcher.lnk」**（只在确认它指向本程序时才删）。
- 卸载时：会结束**本安装目录启动的** NetWatcher 进程（不会误杀其它位置的副本），并删除「IP监控.lnk」和 1.0 遗留的「NetWatcher.lnk」。

> 注意：如果用 `-DataDir` 指定了自定义数据目录，卸载时也要带上同样的 `-DataDir`，`-DeleteData` 才会删除那个目录。

## 三、管理员精确模式与 EStats 限制

### 3.1 两种模式

| 模式 | 条件 | 逐 IP 字节来源 | 界面标注 |
|---|---|---|---|
| **精确** | 以管理员身份运行 **且** 至少有一条连接成功读到 EStats | `GetPerTcpConnectionEStats` 逐连接读取、按采样间隔求差分 | 逐IP精确（绿色） |
| **估算** | 其它情况（含普通权限） | 按 ESTABLISHED TCP 连接数均分整机总流量 | 逐IP估算（橙色） |

- **判据**：只有**确实有一条连接成功读到 EStats** 才显示「精确」。这是对 1.0 bug 的修正——1.0 会无条件标记 `precise=true`，EStats 失败被静默吞掉，造成「逐 IP 字节恒为 0 却显示精确」；2.0 按实际返回值判断，失败时显示**橙色「逐IP估算」**，鼠标悬停可看到最近一次失败原因（`LastEStatsError`）。
- 首次 EStats 失败会把返回码 / Windows 错误码写入数据目录下的 `monitor.log`，便于诊断。
- **EStats 在部分机器/系统上可能不可用**：非管理员通常返回 `ERROR_NOT_SUPPORTED (50)`；管理员也可能失败，返回 `ERROR_NOT_SUPPORTED (50)` / `ERROR_INVALID_USER_BUFFER (1784)`（例如装有网络加速器、LSP/WFP 过滤驱动的环境）。以管理员身份运行 `NetWatcher.exe --selftest`，看 `selftest.log` 里的 `EStats 结论:` 一行即可确认本机是否支持；不可用时程序自动退回「估算」，**不会谎报精确**。

### 3.2 为什么普通权限拿不到逐 IP 精确字节

Windows 出于安全考虑，读取「其它进程/连接」的逐连接字节数需要管理员权限：普通权限调用 EStats 会返回 `ERROR_NOT_SUPPORTED`（错误码 50）。即使以管理员运行，在装有网络加速器 / LSP / WFP 过滤驱动的机器上也可能失败（错误码 50 或 1784），此时程序只能按连接数估算——**这是系统级限制，不是程序缺陷**。

### 3.3 UDP / QUIC 无法逐 IP 归因

Windows 的 TCP 连接表能列出远端的 TCP 连接；而 **UDP 是无连接协议，系统接口不提供 UDP 的远端 IP**，所以：

- UDP 流量（包括基于 UDP 的 **QUIC / HTTP/3**）**无法归因到具体远端 IP**；
- 它**仍然计入整机总流量**，但不会出现在逐 IP / 逐进程的字节统计里；
- 因此当机器上有较多 QUIC 流量时，「逐 IP 字节之和」会**小于**「整机总流量」，这是正常现象。

### 3.4 如何切换到精确模式

- 右键桌面快捷方式「IP监控」→ **以管理员身份运行**；或
- 在程序底部点「以管理员身份重启」。

切换后看窗口顶部的运行模式标注（精确=绿色，估算=橙色）；估算时把鼠标停在标注上可看到 `LastEStatsError`（最近一次 EStats 失败原因）。想确认本机能不能精确，以管理员身份运行 `NetWatcher.exe --selftest`，看 `selftest.log` 里的 `EStats 结论: 可用/不可用(原因)`。

## 四、数据存储

数据目录默认 `%APPDATA%\NetWatcher\`：

| 文件 / 目录 | 内容 |
|---|---|
| `data\YYYY-MM-DD.json` | 每天的统计（JSON，可直接查看）；含总流量、逐 IP、逐进程、采样曲线 |
| `config.json` | 配置（扫描间隔、保留天数、归属地开关等） |
| `geocache.json` | IP 归属地缓存 |
| `monitor.log` | 运行日志（含 EStats 失败诊断） |
| `crash.log` | 未处理异常导致的崩溃日志（排查用） |
| `ui-error.log` | 界面/UI 线程异常日志（排查用） |
| `selftest.log` | `--selftest` 自检输出 |

- 写盘是**原子**的：先写 `*.json.tmp`，再用替换/移动覆盖正式文件，避免断电或崩溃产生半个文件。
- 采样的分钟曲线每天最多 1440 条；写盘有节流（默认至少间隔 15 秒，跨日或退出时强制写）。
- 用 `--datadir <路径>` 可指定其它数据目录（见下一节）；安装脚本的 `-DataDir` 会把该参数写进开机自启命令。
- 数据只保存在本机；卸载默认保留数据，只有 `uninstall.ps1 -DeleteData` 才删除。

## 五、命令行参数

| 参数 | 作用 |
|------|------|
| （无参数） | 启动图形界面 |
| `--background` / `-b` / `--minimized` | 后台启动（只驻留托盘，不显示主窗口，用于开机自启） |
| `--selftest` / `--test` | 运行自检，诊断写入数据目录下的 `selftest.log` |
| `--daemon <秒>` | 无界面采集指定秒数后退出（便于测试/纯后台采集） |
| `--mutex-tag <标签>` | 给本次实例的互斥量加标签，便于在同一台机器上同时运行多个测试实例；常规使用不需要 |
| `--datadir <路径>` | 指定数据目录 |
| `--autostart-on` / `--autostart-off` | 命令行开启/关闭开机自启（写 HKCU 启动项，不需要管理员） |

补充说明：

- `--daemon <秒>`：无界面采集指定秒数后自动退出，退出时在数据目录写 `daemon.log` 汇总（采样数、总流量、IP/进程数、是否精确），用于测试或纯后台采集。
- `--mutex-tag <tag>`：给单实例互斥名加后缀（默认 `NetWatcher_SingleInstance_Mutex`，加 tag 后为 `…_<tag>`），便于在同一台机器上并行运行多个测试实例；常规使用不需要。
- 崩溃日志：未处理异常写入 `<数据目录>\crash.log`，界面/UI 线程异常写入 `<数据目录>\ui-error.log`（`<数据目录>` 为 `--datadir` 指定目录，未指定则 `%APPDATA%\NetWatcher`），用于排查“静默退出”。

### 自检说明（`--selftest`）

自检会把诊断写到 `<数据目录>\selftest.log`，包括：

- 管理员状态、进程位数、操作系统版本；
- 网卡统计（每个网卡的名字与收发字节，并标明 Loopback / Tunnel 是否被排除）；
- TCP 连接总数 / ESTABLISHED 数 / 远端连接数（前 15 条）；
- **EStats 诊断**：对前几条连接尝试 `rw=1/4 × rod=48/16/1024` 六种组合，逐条打印 `rc/winerr`，并重读确认字节增长——这是判断管理员精确模式能否工作的唯一依据；
- GeoIP 查询、存储读写、开机自启注册表、目录列表；
- 结论行：`EStats 结论: 可用/不可用(原因)`。

普通权限下自检仍会尝试 EStats，但结论会是「不可用（当前非管理员，需以管理员身份运行）」；想验证精确模式请以管理员身份运行自检。

## 七、技术说明与限制

- **技术栈**：C#（C# 5 语法）/ .NET Framework 4.8 / WinForms，P/Invoke 调用 `iphlpapi.dll`（`GetExtendedTcpTable`、`GetPerTcpConnectionEStats` 等）。
- **连接枚举**：TCP 连接（含 IPv6）普通权限即可枚举，含 PID、进程名、进程路径、进程启动时间。
- **总流量口径**：整机累计收发只统计处于 Up 状态、且**排除 Loopback / Tunnel** 的网卡，避免与逐 IP 统计口径不一致。
- **逐 IP 字节**：管理员 + EStats 成功时为每个 TCP 连接的精确差分；否则为按连接数估算。估算值在数据里也标记为非精确。
- **UDP / QUIC**：系统不提供 UDP 远端 IP，无法逐 IP 归因；UDP 流量只计入整机总流量（见第三节）。
- **受保护进程**：个别系统/受保护进程可能读不到进程名或完整路径，界面显示为「(未知)」。
- **IP 归属地**：使用 `ip-api.com` 免费接口（中文城市名），首次遇到的新 IP 在后台异步解析并缓存，不阻塞监控；内网/本机地址自动识别为「本地/内网地址」，不发起联网查询。查询时**绕过系统代理**（程序硬编码 `Proxy = null`），避免某些机器上系统代理配置导致归属地查询超时。
- **逐 IP 精确流量的已知限制**：精确模式依赖 Windows `GetPerTcpConnectionEStats`。该接口在部分机器/系统上会失败，返回 `ERROR_NOT_SUPPORTED (50)` / `ERROR_INVALID_USER_BUFFER (1784)`（例如装有网络加速器、LSP/WFP 过滤驱动的环境；本仓库开发机实测即如此，换用 `ref struct + IntPtr`、`byte[]`、指针 row 三种封送方式结果一致，怀疑与 Steam++ Accelerator 之类的网络加速驱动有关）。此时程序自动降级为「估算」并在状态栏/tooltip 标注，**不会谎报精确**。用 `NetWatcher.exe --selftest`（**以管理员身份运行**）查看日志里的 `EStats 结论:` 一行即可确认本机是否支持；自检会打印 `rw=1/4 × rod=48/16/1024` 六种组合的 rc/winerr。
- **数据模型**：逐 IP 的 `sessionCount` 是真实会话数（由「无连接」变「有连接」的次数），`sampleCount` 是出现过的采样次数；逐进程的 `connCount` 是连接出现次数（每个连接只计一次），都不再随采样次数虚增。
- **已知限制**：估算模式下逐 IP 字节不能反映真实占比；Wi-Fi/虚拟网卡较多时网卡合计可能与运营商侧统计有差异；归属地数据库由第三方接口提供，城市可能不准确。

## 八、隐私

- 所有连接记录、进程信息、流量数据**只保存在本机**，程序不会主动上传任何记录。
- 唯一的联网行为是查询公网 IP 的归属地：只发送 IP 地址字符串（不含端口、进程、流量信息），结果缓存在本地。
- 关闭「IP 归属地识别」后，程序完全不发起任何网络查询。
- 项目**没有**遥测、账号体系或云同步功能。

## 九、项目结构

```
├── src/                   # 源码

│   ├── MainForm.cs        # 图形界面 + 托盘
│   ├── SettingsForm.cs    # 设置窗口

│   ├── Storage.cs         # 按日期 JSON 存储（原子写盘）
│   ├── GeoIp.cs           # IP 归属地（后台解析 + 缓存）
│   ├── Config.cs          # 配置
│   └── Json.cs            # JSON 小工具
├── bin\NetWatcher.exe     # 编译产物（主程序）
├── app.ico                # 图标
├── build.bat              # 编译脚本
├── install.ps1            # 安装（数据目录 / 开机自启 / 桌面快捷方式）
├── uninstall.ps1          # 卸载（-DeleteData 才删数据）
├── docs\design-2.0.md     # 2.0 设计契约（开发用）
└── README.md              # 本文件
```
