# IP监控1.0 · 网络连接监控（NetWatcher）

> 项目代号：**IP监控1.0**

一个在 Windows 上运行的**常驻后台**网络连接监控工具，图形化界面，记录电脑每次连接了哪些 IP、收发数据量、连接时长，并自动识别 IP 归属地（精确到城市）。

- 零依赖、零安装：纯 C# 编写，用 Windows 自带的 .NET Framework 4.x 编译器编译成单个 `NetWatcher.exe`，双击即可运行。
- 数据按**日期**归档，可查看今天 / 昨天 / 前天或任意一天。

---

## 一、功能特性

| 功能 | 说明 |
|------|------|
| 连接记录 | 定时扫描 TCP 连接，记录远端 IP、端口、进程名、PID、连接状态 |
| 进程视图 | 资源监视器式**树形图**：应用程序 → PID → 远端IP（含端口/协议/字节），按活跃度排序 |
| 流量统计 | 每个 IP / 每个进程的累计下载/上传字节、平均速率、峰值速率 |
| 连接时长 | 每个 IP 的累计连接时长、连接次数、首次/最近连接时间 |
| IP 归属地 | 每个 IP 识别到**城市**级（国家 + 省市 + 城市 + 运营商），本地缓存 |
| 总流量 | 整机累计上行/下行字节、实时上下行速率、当日峰值 |
| 实时视图 | 当前各 IP 的连接数与实时上传/下载速度、连接明细 |
| 按日查看 | 今天 / 昨天 / 前天 + 日历选择任意日期 |
| 历史概览 | 各日期的总流量、峰值、IP 数、采样次数 |
| 导出 CSV | 把某一天的统计导出为 CSV（可用 Excel 打开） |
| 后台常驻 | 关闭窗口最小化到系统托盘，监控持续运行 |
| 开机自启 | 写入 HKCU 启动项，登录后自动在后台运行 |

## 二、使用方法

1. 双击 `bin\NetWatcher.exe`（或**桌面快捷方式「NetWatcher」**）启动，主窗口会显示四个标签页：
   - **实时连接**：顶部是整机实时上下行速度与今日累计；下方是各 IP 的实时速率和连接明细。
   - **进程视图**：树形图「应用程序 → PID → 远端 IP:端口(协议)」，每个节点显示收发字节与连接次数，按活跃度从高到低排序；顶部是当日汇总（进程数、远端 IP 数、累计连接次数、总下载/上传、峰值）。
   - **按日统计**：查看所选日期的逐 IP 明细（城市、运营商、时长、流量、平均/峰值速率）。
   - **历史概览**：各日期的汇总对比。
2. 顶部按钮 `今天 / 昨天 / 前天` 或日历框切换日期。
3. **关闭窗口**会最小化到系统托盘（右下角图标），不会退出；右键托盘图标可选“显示主窗口 / 刷新 / 创建桌面快捷方式 / 退出”。
4. 点击 **设置** 可修改：
   - 扫描间隔（1 分钟更精细 / 5 分钟更省资源）
   - 开机自动启动
   - 数据保留天数（0 = 永久保留）
   - IP 归属地识别开关

## 三、关于“逐 IP 精确流量”（管理员模式）

- **普通用户模式（默认）**：精确记录每个 IP 的连接/时长/进程/端口 + **精确的整机总流量**与速率；逐 IP 的收发字节按“活跃连接数”**估算**，界面上标注“估算”。
- **管理员模式（可选）**：点击主界面“以管理员身份重启（逐IP精确流量）”，通过 Windows 的 `GetPerTcpConnectionEStats` 接口读取**每个 TCP 连接的精确收发字节**，实现逐 IP 精确流量。

> 说明：Windows 出于安全，普通权限无法读取其它进程/连接的逐连接字节数，这是系统级限制。

## 四、数据存储

- 数据目录：`%APPDATA%\NetWatcher\`
  - `data\YYYY-MM-DD.json` —— 每天的统计（JSON 格式，可直接查看）
  - `geocache.json` —— IP 归属地缓存
  - `config.json` —— 配置
- 用 `--datadir <路径>` 可指定其它数据目录（见命令行参数）。

---

## 五、命令行参数

| 参数 | 作用 |
|------|------|
| （无参数） | 启动图形界面 |
| `--background` / `--minimized` | 后台启动（只驻留托盘，不显示主窗口，用于开机自启） |
| `--selftest` | 运行自检并输出诊断到数据目录下的 `selftest.log` |
| `--daemon <秒>` | 无界面采集指定秒数后退出（便于测试/纯后台采集） |
| `--datadir <路径>` | 指定数据目录 |
| `--autostart-on` / `--autostart-off` | 命令行开启/关闭开机自启 |

## 六、重新编译

双击 `build.bat`（或运行）：

```
build.bat
```

它会用系统自带的 `csc.exe` 重新生成 `bin\NetWatcher.exe`（无需安装任何开发工具）。

## 七、技术说明与限制

- **技术栈**：C#（C#5 语法）/ .NET Framework 4.8 / WinForms，P/Invoke 调用 `iphlpapi.dll`（`GetExtendedTcpTable`、`GetPerTcpConnectionEStats`）。
- **连接枚举**：TCP 连接（含 IPv6）普通权限即可枚举，含 PID 与进程名。
- **进程名**：通过系统进程表解析 PID → 进程名（如 `Weixin`、`chrome.exe`）。个别受保护的系统进程可能显示为“(未知)”。
- **逐 IP 字节**：精确值需管理员权限（EStats）；普通权限下为按连接数估算。
- **UDP**：UDP 为无连接协议，系统连接表不提供远端 IP，故不纳入逐 IP 记录（仍计入整机总流量）。
- **IP 归属地**：使用 `ip-api.com` 免费接口（中文城市名），首次遇到的新 IP 在后台异步解析并缓存，不会阻塞监控；内网/本机地址自动识别为“本地/内网地址”，不发起联网查询。
- **隐私**：所有数据只保存在本机，不主动上传任何连接记录；唯一的联网行为是查询公网 IP 的归属地（仅 IP 地址，不含端口/进程/流量信息）。

## 八、项目结构

```
NetWatcher/
├── src/                 # 源码
│   ├── Program.cs       # 入口、命令行、自检、开机自启
│   ├── MainForm.cs      # 图形界面 + 托盘
│   ├── SettingsForm.cs  # 设置窗口
│   ├── Monitor.cs       # 监控引擎（采样、聚合、落盘）
│   ├── NativeMethods.cs # P/Invoke 网络接口
│   ├── Storage.cs       # 按日期 JSON 存储
│   ├── GeoIp.cs         # IP 归属地（后台解析 + 缓存）
│   ├── Config.cs / Json.cs
├── bin\NetWatcher.exe   # 编译产物（主程序）
├── app.ico              # 图标
└── build.bat            # 编译脚本
```
