## 七、如果下一次会话要继续（给 AI/接手者的建议）

1. 先读：`README.md` → `docs/2.1-交接说明.md`（本文件）→ `docs/踩坑与决策记录.md`（§八）→
   `docs/design-2.1.md` → `docs/开发与维护指南.md`。
2. 环境自检（在 `2.1\` 目录）：
   - `cmd /c build.bat` 能过（版本资源 2.1.0.0）；
   - `tools\qa\regression-p0.ps1` 应 PASS=29/29、`regression-p1.ps1` 应 PASS=38/38；
   - `tools\qa\verify.ps1 -SkipGui -Seconds 30`：产品检查应全 PASS；若 `REALDATA_UNTOUCHED` FAIL，
     先确认是否用户 2.0 实例在写真实数据（用闲置对照组归因），**不要改判、不要削弱守卫**；
   - **任何测试都带绝对 `--datadir` 临时目录**，不要写 `%APPDATA%\NetWatcher`；
   - 启动 GUI 用 `Invoke-CimMethod Win32_Process Create`；结束进程只按自己记录的 PID，禁止按进程名杀。
3. 已知"不要再踩"的坑：见 `docs/踩坑与决策记录.md`（§一~§八，尤其 §八 2.1 新坑）。
4. **跑 2.1 前先确认没有 2.0 实例在写数据**（共用数据目录；2.1 写锁管不到 2.0）。
5. 真机安装/卸载之前先让用户退出 2.0；安装后确认 2.0 的自启/快捷方式/数据未被改动。
