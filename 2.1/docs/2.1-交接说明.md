### 4.4 2.1.1 托盘修复（2026-10-31 真机使用反馈）

- 现象：任务栏通知区域出现一堆重复图标，鼠标划过才消失（Windows 典型"幽灵图标"）。
- 根因（源码级）：`EnsureTray()` 反复 `Visible=false→true`；`--background`/`StartMinimized` 启动后
  30 秒内每 3 秒重加一次（10 次），二次启动与 `TaskbarCreated` 也会重加；且 `ExitApp()` 未停补偿定时器，
  退出竞态可能再次 `BuildTray()` 留下幽灵图标。
- 修复：启动只重建一次并立即停表；`EnsureTray()` 不再 toggle；`ExitApp()` 先停表再释放；
  `BuildTray()` 单实例保护；新增 `--quit/--exit` 优雅退出（保存数据、移除图标），
  回归 `tools/qa/regression-quit.ps1` = **6/6 PASS**。

### 4.7 2.3.0 加密小时文件存储（2026-11-01 定版）

- 需求：用户要求 IP 数据按小时落盘、开机新文件、实时落盘防断电、文件加密只能本程序读、文件名带时间戳与独特后缀、按日期查看要快。
- 实现：`.nwipdb` 加密小时文件（命名 `监控_<日期>_<小时>_s<启动>.nwipdb`；每小时一个、每次启动新建）；AES-256-CBC(PKCS7)+HMAC-SHA256+GZip（encrypt-then-MAC）；主密钥 32B 随机、DPAPI(CurrentUser) 保护于 `data\.storekey`（magic `NWKEY001`，entropy `NetWatcher2.3.HourStore.DPAPI.Entropy.v1`）；明文头 76B 仅元数据（magic `NWIPDB01`、版本、flags、小时/会话起点、汇总字节/峰值/采样数/IP 数/进程数），IP/进程明细全在密文。字节布局详见 `docs/design-2.1.md` §13。
- 落盘：Monitor `current`/`currentHour` 双聚合同一增量更新；每采样 `SaveHour(currentHour.Clone())` 加密原子重写（不再 15s 节流，断电最多丢 <1 采样）；跨整点 flush→新建空文件；跨日重置天级；退出 flush 当前小时。
- 迁移：`MigrateLegacyOnce`（GUI/daemon 拿到写锁创建 Monitor 时一次）扫描旧 `data\*.json` → 加密 legacy `.nwipdb` → 回读校验（JSON 可解析 + bytesIn/Out/peak/sampleCount 一致 + ips/procs 数一致）→ 删除原 JSON；失败保留原文件并写 `monitor.log`；幂等；`--selftest` 不触发迁移。
- 历史概览：单文件日只读 76B 明文头；多文件日 `LoadDay(date).SummaryOnly()` 解密合并去重（修复"各文件头计数相加偏大"，`d634622`）；`GetHistory` 用 SummaryOnly 缓存。
- 验证：回归 **7 套件 208 项全 PASS（0 FAIL / 0 WARN / 0 TODO）**（p0 32/32、p1 39/39、activation 9/9、quit 6/6、headless 35/35、GUI 59/59、H1–H7 28/28；`_analysis\v230-验收\02-回归.md`）；签名 exe 153,488 B / 2.3.0.0 / `Valid` / SHA256 `E129A678…`；真机 UI 验证 **PASS=109 / FAIL=0 / WARN=0**（迁移 15ms / 历史 610.78·811.90MB 0% 误差 / 每次启动新增小时文件 / 加密无明文 / 损坏·错 key 不崩溃 / 30 天性能 0·1·20·36ms / 5 标签 / 真实数据零改动；未实机：真实跨整点·跨日、断电、换机不可读，见 `03-真机验证.md` §9）。
- 限制：迁移不可逆/回退 2.2.x 读不到；仅本机本用户可读（换机/换用户不可解密）；跨整点/跨日未实机触发（注入时钟/静态覆盖）；写放大（1s 高频建议后续改增量）；同秒两次启动覆盖同名空文件（影响可忽略）。
