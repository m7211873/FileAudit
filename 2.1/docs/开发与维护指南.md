## 三、启动顺序（2.1 版，别改乱）

```
Main(args)
 ├─ 解析参数（--background/--datadir/--mutex-tag/--selftest/--daemon/--autostart-*/--show）
 ├─ --autostart-on/off：只写/删 HKCU Run\NetWatcher2.1 后退出（不碰 2.0 的 NetWatcher）
 ├─ AppConfig.Load(dataDir) → 用 Startup.IsEnabled() 对账 AutoStart（P1-5）→ Store.Init → GeoIp.Init → startup.log
 ├─ --selftest：只读自检（不写 data\、不触发迁移、不改自启、不抢写锁）后退出
 ├─ --daemon N：抢数据写锁（失败 exit 2）→ 采集 N 秒 → 退出（写 daemon.log）
 ├─ 单实例：Mutex NetWatcher2.1_SingleInstance_Mutex；已存在则 Set 唤出事件后退出
 ├─ 抢数据写锁 NetWatcher2.1_DataLock_<MD5(数据目录小写绝对路径)>（失败提示后退出；管理员升级时最多重试 5 秒）
 ├─ 加载当天已有 DayData（同日重启接续，2.1 P0）
 ├─ startHidden = background || (StartMinimized && !--show)（P1-6）
 ├─ Monitor.Start()            ← 引擎先于界面启动（UI 挂掉也不影响采集）
 ├─ Application.Run(MainForm(cfg, background, monitor, activateEvent, dataDir))
 └─ finally: monitor.Stop()；释放数据写锁
```

MainForm 生命周期（沿用 2.0）：
```
构造：BuildUi() → BuildTray() → timer(1s)
OnLoad：SetupSplitter → UpdateHeader → ForceRefresh → timer.Start
        → StartActivationListener（命名事件 → ShowMain）
        → background: 隐藏窗口 + 30 秒内每 3 秒 EnsureTray()
WndProc：TaskbarCreated → EnsureTray()（资源管理器重启后补托盘图标）
关闭窗口：隐藏到托盘（不退出）；托盘菜单「退出」才 ExitApp()
```

## 四、数据模型与聚合规则（2.3.0：加密小时文件）

```csharp
DayData { date, hourStartUnix, sessionStartUnix,
          bytesIn/Out, peak*, sampleCount, bytesPrecise,
          ips: Dictionary<ip, IpAggregate>,
          procs: Dictionary<"进程名|PID|进程启动时间", ProcAgg>,
          samples: List<[minuteUnix, bytesIn, bytesOut]> }   // 每小时文件存该小时分钟桶；合并后每天最多 1440

IpAggregate { ip, bytesIn/Out, peakIn/OutBps, connectedSeconds,
              sampleCount(出现过的采样次数), sessionCount(真实会话数),
              first/lastSeenUnix, processes(采样出现次数), states, ports,
              city/region/country/isp, bytesPrecise, isNew(仅UI，不落盘) }

ProcAgg { name, path, pid, processStartUnix, bytesIn/Out, connCount(真实新增连接数),
          first/lastSeenUnix, ips: Dictionary<ip, IpConnAgg> }
```

存储（`Storage.cs`，详见 `docs/design-2.1.md` §13）：

- `data\监控_<yyyy-MM-dd>_<HH-00-00>_s<HHmmss>.nwipdb`：**加密小时文件**（76B 明文头 + 16B IV + 密文 + 32B HMAC；AES-256-CBC(PKCS7)+GZip；主密钥 DPAPI 保护于 `data\.storekey`，`macKey=HMAC-SHA256(masterKey,"NetWatcher2.3.HourStore.HmacKey.v1")`）。
- 每小时一个、**每次启动新建**；`LoadDay(date)` 合并当天所有小时文件（+legacy 日块：bytes/peak/sampleCount 相加/最大、IP/进程聚合求和、samples 按分钟排序去重）。
- `LoadDaySummary(date)`：单文件日只读 76B 明文头；多文件日 `LoadDay(date).SummaryOnly()` 解密合并去重（历史概览用）。
- 迁移 `MigrateLegacyOnce`：旧 `data\*.json` → legacy `.nwipdb` → 回读校验 → 删明文；失败保留原文件并写 `monitor.log`；`--selftest` 不触发。
- 保留期 `EnforceRetention` 按文件名日期删 `.nwipdb`/`.json`；`.storekey` 不删。坏文件/坏密钥跳过并记日志。

采样规则（`Monitor.Sample`）：
1. 枚举 TCP（IPv4+IPv6），**丢弃 LISTEN/CLOSED**，其余有远端的状态都记录（`ShowLocalIp=false` 时再过滤内网）。
2. 整机字节差分 → 速率；**同一份增量并行更新当天 `current` 与当前小时 `currentHour`**。
3. 精确路径（管理员）：每条 ESTABLISHED 的 IPv4 连接 enable EStats → 读累计 → 差分；失败则本轮降级。
4. 估算路径：整机增量按 **ESTABLISHED 连接数均分**（余数给最后一条，保证合计不丢字节）。
5. 更新 `current`/`currentHour`（IP/进程聚合、分钟桶、峰值）；`isNew` = 当天首次出现。
6. 构造 `Snapshot`（UI 只读）→ UI 每秒取一次，仅 `LastScan` 变化时重绑表格。
7. **（2.3.0）每采样** `Store.SaveHour(currentHour.Clone())` 加密原子重写当前小时文件（不再 15s 节流）；每 300 采样清理保留期。
8. **（2.3.0）跨整点** `CheckHourRotation`/`RotateHour`：flush 旧小时 → 新建空小时文件 → 新 currentHour（当天聚合不清空）；**跨日** `RotateDay` flush 后重置天级并新建小时会话。
9. **（2.3.0）启动**：`MigrateLegacyOnce` → `LoadDay(today)` 合并 → `BeginHourSession` 新建本次空小时文件；同日重启接续（P0-1）。
10. **（2.1）** 1.0 旧数据"假精确"降级：`LoadDay` 发现 `bytesPrecise=true` 但逐 IP 字节合计=0 时改为估算（P1-9）。
11. **（2.1）** UI 刷新节流：实时页每次采样刷新；进程/按日页 ≥5s、历史页 ≥15s 才重建表格（P1-11）。
12. **（2.1）** EStats 首次失败写 `monitor.log`；`precise` 恢复后清空 `lastEStatsError`（P1-12）。

### 4.1 2.1 的数据写锁（实现要点）

- 位置：`Program.Main`，在 GUI/daemon 进入写数据路径**之前**抢；`--selftest` 不抢。
- 名字：`NetWatcher2.1_DataLock_<MD5(数据目录绝对路径小写)>`；MD5 用 `System.Security.Cryptography.MD5`
  对 UTF-8 字节求哈希，转小写十六进制（与跨进程稳定一致即可）。
- 语义：命名 Mutex `createdNew == false` → 已被占用（`AbandonedMutexException` 视为可接管）：
  - `--daemon`：立即 `Environment.Exit(2)`（脚本据此判断；2.1 实测 0.2s 退出）；
  - GUI：弹标题为 **「IP监控2.1」** 的 `MessageBox`（`#32770`）提示后退出；
    管理员重启/升级场景最多重试 5 秒（每秒 4 次）尝试接管；
  - 退出前写 `startup.log`/`daemon.log` 一行原因，便于排查。
- 生命周期：持有到进程退出（`finally` 释放）；OS 在进程崩溃时自动释放，不会留下"死锁"。
- 注意：`--mutex-tag` **不能**用于绕过写锁（它只改单实例互斥量名）；测试并行用不同 `--datadir`。

### 4.2 2.1 的自检（`--selftest`）纪律（2.3.0 扩展）

- 只读：不得写 `data\`（不建 `.nwipdb`、不迁移、不改 `config.json` 之外的用户数据）；
  存储读写测试写 `<datadir>\selftest-store\` 临时子目录（自建、用后删除）；
- **2.3.0 存储自测内容**：小时文件加密往返（SaveHour→LoadDay 字段一致、magic `NWIPDB01`）、加密性（二进制/无明文 IP/无 `"ips"`）、
  明文头摘要（LoadDaySummary 只读 76B）、legacy JSON 迁移（合成数据）、H7 性能两行（24 文件合并/30 天首载）、
  「真实 `data\` 未被 selftest 改写」护栏；
- **`--selftest` 不触发真实数据迁移**（迁移只在 GUI/daemon 拿到写锁创建 Monitor 时执行）；
- 不写/删 `HKCU\...\Run\NetWatcher2.1`（以及 2.0 的 `NetWatcher`），只读检查并打印状态；
  注册表往返测试用临时值名 `NetWatcher2.1_SelfTest_<PID>`，测完删除；
- 不抢数据写锁；
- 允许写 `<datadir>\selftest.log`、`selftest-store\` 临时测试目录与一次 GeoIP 查询的 `geocache.json` 缓存。

## 六、常见修改场景

### 6.1 加一个统计字段（例如"平均包大小"）

1. `Storage.cs` 的 `IpAggregate` / `ProcAgg` 加 `public long ...` 字段（旧数据缺失自动取默认值，**不要改名/删旧字段**）。
2. `Monitor.Sample` 在聚合处累加。
3. `MainForm` 的表格列定义 + `FillRows` 填充 + 排序 key 映射。
4. 更新 `CHANGELOG.md`（2.1 段）。

### 6.2 新增一个标签页

- `MainForm.BuildUi` 里 `tpXxx` + `AddTab("标题", page)`；
- 参考已有页的 TLP 分行方式（**不要**在同容器混用 Dock.Fill 与 Dock.Top）；
- 刷新在 `RebindActiveTab()` / `OnTimerTick` 里按当前选中页处理；
- 截图验收 + 更新用户手册截图（`docs/screenshots/`）。

### 6.3 想让"精确模式"可用（本机 EStats 不可用）

- 先确认：管理员 `--selftest` 的 `EStats 结论:`。若为不可用，代码侧无解。
- 替代方案：ETW `Microsoft-Windows-Kernel-Network`（可覆盖 UDP/QUIC，需要管理员 + 自己写 ETW 消费者，
  C# 无 NuGet 情况下约 500~800 行 P/Invoke，工作量大）。建议单独立项，不要混在 2.x 小版本里。

### 6.4 调整采样间隔

- `Config.AllowedIntervals`（默认 2 秒，档位 1/2/5/10/30/60）+ `SettingsForm` 的下拉项文案；
- 注意 CPU：1 秒档更全但更耗资源；落盘节流固定 15 秒不需要改。

### 6.5 改安装目录 / Run 值 / 快捷方式（2.1 命名）

- 四处必须同时改，缺一都会出现"装到新位置但旧值残留"：
  1. `2.1/src/Program.cs`：`Startup.ValueName = "NetWatcher2.1"`、安装目录相关常量（若有）；
  2. `2.1/install.ps1`：`$InstallDir`、`$RunValueName`、`$ShortcutName`；
  3. `2.1/uninstall.ps1`：同上（必须与安装脚本一致，否则卸载不干净）；
  4. `2.1/docs/`（用户手册 §2/§8）与 README。
- 根目录 2.0 的值（`Run\NetWatcher`、`IP监控.lnk`、`Programs\NetWatcher`）**永远不要**在新脚本里引用为"要删除的目标"。

### 6.6 改 `--selftest`（危险区）

- 只能读数据，**禁止**写 `data\`（不建 `.nwipdb`、不建/覆盖 `.json`、不触发 legacy 迁移）；存储测试用 `selftest-store\` 临时子目录；
- 只能读注册表 Run 值，**禁止**对真实值 `SetValue` / `DeleteValue`；往返测试用临时值名；
- 不要抢数据写锁（否则同一目录的自检会被"正在运行"的实例挡住）；
- 改完必须验证：`--selftest --datadir <临时目录>` 前后 `data\` 文件列表（`.nwipdb`/`.json`/.storekey）与 `Run\NetWatcher2.1` 零变化。

### 6.7 P1 行为的改动点（改动前先看，别改回去）

| 项 | 文件 | 关键实现 |
|---|---|---|

## 七、代码规范（沿用现状）

- C# 5 语法；`delegate {}` 匿名方法而非 lambda（历史代码风格，二者都能编译）。
- 所有可能抛异常的 P/Invoke / 文件 IO 必须 `try/catch` 且有降级，不允许让 UI 线程崩溃；
  引擎线程的异常写入 `monitor.log`。
- 线程安全：`Monitor` 的 `current` 只在 `liveLock` 内改；对 UI 只返回**深拷贝**（`Clone()`）。
- 路径：一律 `Path.Combine`；数据目录用 `AppConfig.EffectiveDataDir()`，**不要硬编码**。
- 命名 MuteX/Event/注册表值名集中定义在 `Program.cs`（`Startup` 类/常量），不要在 UI 层散落字符串。
- 中文：界面文案统一简体（国家名有归一化 `NormalizeCn`）。
- 提交信息中文、说明"为什么"；改动涉及行为时同步 `README.md` / `CHANGELOG.md` / `docs/`。
