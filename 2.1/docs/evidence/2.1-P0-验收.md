## 4. FAIL 归因与对照证据

### 4.1 SELFTEST_GEOIP（环境网络，间歇性）

- 现象：`-SkipGui` run（16:26 前后）`GeoIP(8.8.8.8): 未知 [来源:error]`，脚本按设计自动重跑一次 selftest 后仍失败；约 1 分钟后 GUI run（16:27:03）同一检查 **PASS**：`美国 弗吉尼亚州 Ashburn · Google LLC`（`LookupSync` 联网解析成功后按既有实现标记来源为 cache）。
- 旁证：2.0 基线验收（`_analysis\qa-report.md` §3.4/3.5）已独立实测本机到 `ip-api.com` 超时，并把同类 FAIL 归因网络；本次不是 2.1 代码回归。
- 处理：**如实保留 FAIL**，未改脚本判据、未重跑挑结果。

### 4.2 REALDATA_UNTOUCHED（用户实例实时写入，非被测程序污染）

隔离证明（被测程序不可能写真实目录）：

1. 所有被测实例均显式 `--datadir` 于 `%TEMP%\ipmon-qa-*` / `ipmon-p0reg-*`，脚本有双重守卫（`--datadir` 下无数据即杀进程、运行前后快照对比）。
2. 被测实例的 GeoIP 缓存实际写到临时目录：`%TEMP%\ipmon-qa-20261031-162552\geocache.json`、`%TEMP%\ipmon-qa-20261031-162657\geocache.json`、`…\mutex-b\geocache.json`；GUI 实例 `startup.log` 明确记录 `启动 exe=C:\…\Temp\ipmon-qa-run-20261031-162657\NetWatcher.exe 数据目录=C:\…\Temp\ipmon-qa-20261031-162657\gui 管理员=False`。
3. **对照组实验**（`tools\qa\out\control_realdata_p21_20261031-162809.txt`）：16:28:09–16:28:54 **45 秒闲置、未启动任何被测进程**，真实目录 `data\2026-10-31.json` 仍变化（size 216,443→216,451，SHA256 `DBCC953A…`→`CA0748DD…`），且 PID 10856 前后均存活 → 变化来自用户实例。
4. 真实 `geocache.json` mtime=16:27:11（落在 GUI run 窗口内）；被测实例同期只写各自 temp geocache（见 2）。
5. 全程 `Get-Process` 记录：除 PID 10856 外无其它 NetWatcher 常驻；本脚本启动的 GUI/daemon 均按记录 PID 结束并 PASS `CLEANUP_*`。

结论：`REALDATA_UNTOUCHED` 的 2 个 FAIL 是**环境既有事实**（用户管理员实例持续写真实数据），不是 2.1 程序写真实目录，也不是本次测试污染；原始快照 diff 保留在 verify 报告的 `[FAIL]` 行与 `report_*.json`。

## 7. 限制与风险

1. `REALDATA_UNTOUCHED` 在用户管理员实例持续运行期间**必然**周期性 FAIL；这是随环境变化的既有事实，不宜作为 2.1 代码判据（本报告用对照组归因，未改判）。
2. `SELFTEST_GEOIP` 依赖外网 `ip-api.com`，本机间歇不可达，可能偶发 FAIL；与 2.0/2.1 代码无关。
3. 本机 csc 构建非确定性（PE 时间戳），跨构建 SHA256 不可直接比对；一致性以「同时刻源 exe == 运行副本」为准。
4. GUI 真实鼠标点击类检查历史上偶发（2.0 复跑曾出现一次标签[0]），本次 4/4 PASS；如需交叉确认可再跑一次 GUI 冒烟（本次未重跑挑结果）。
5. 本次验收运行在**非管理员** shell：EStats 精确模式路径按 design §1 预期不可用，`bytesPrecise=false` 且逐 IP 字节与 day 精确对账（误差 0），符合预期。

## 8. 最终结论

**IP监控2.1 的 P0 四项修复经独立回归验证全部成立**：同日重启接续当天数据（R1）、selftest 不再写/覆盖当天数据（R2，SHA256 级证据）、selftest 不再改真实 HKCU Run 自启值（R3，双值前后完全一致且无残留）、同一 datadir 单写实例（R4，daemon exit=2 + GUI 存活 + 数据未破坏 + daemon.log 冲突记录），另加 Store 临时文件唯一名（R4 无过期 .tmp）。

`verify.ps1` 两次运行共 3 个 FAIL 全部为环境归因（外部 GeoIP 网络 1 次、用户实例写真实数据 2 次），**没有任何产品功能/数据链路/GUI 检查失败**。结论按原始日志如实呈现，未改判、未删证据。
