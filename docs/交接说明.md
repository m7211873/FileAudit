## 四、本次会话完成清单（按目标）

1. **读懂仓库**：梳理了 FileAudit v1（PowerShell 文件审计）→ IP监控1.0（C# WinForms）的演进与项目精神
   （零依赖单 exe、常驻后台+托盘+自启、中文界面、按日归档、自检、诚实标注限制、数据只留本机、文档详尽）。
2. **实测 1.0 并定位真实缺陷**（不是猜的）：逐 IP 字节全 0 却标"精确"、EStats 失败被吞、
   界面标签栏被遮挡、连接次数虚高、总流量含 Loopback/Tunnel。
3. **重写 2.0**：引擎（EStats 探测/差分、聚合、分钟桶、原子写、进程路径/启动时间）、
   界面（四标签页、排序/搜索/复制/筛选/NEW/托盘）、设置页、安装/卸载/签名/验收工具链、全套文档。
4. **真机验收**：截图、鼠标点四个标签页、列头排序、CSV 导出、关闭到托盘、`--background` 启动；
   headless 回归 PASS=27/FAIL=0；真实数据零改动守卫通过；45 秒覆盖对照"漏记 0"。
5. **可用性修复**：定位"进程在但没数据/托盘异常/自启像失效"的根因（**受限目录只能写工作区**），
   改为安装到 `%LOCALAPPDATA%`，并做了引擎解耦、二次启动唤出窗口、托盘自愈。

## 五、待办 / 未完成（按价值排序）

1. **EStats 精确模式**：本机不可用已确认（管理员 `rc=50/winerr=122`）。若一定要"逐 IP 精确"，
   需要 **ETW（Kernel-Network provider）** 方案：可同时覆盖 UDP/QUIC，但需要管理员权限 + 自写 ETW 消费者，
   估计 0.5~1 天，建议单独排期（见 `开发与维护指南.md` §6.3）。
2. **分发签名**：当前自签名只解决本机。要给别人用不报毒/不弹 SmartScreen：
   SignPath Foundation（开源免费，推荐先试）或 Certum 个人版 ≈600 元/年。
   注意 EV 已无性价比；Azure Trusting Signing 对中国大陆主体不开放。
3. **UDP/QUIC 归因**：与 1 绑定；不承诺，除非上 ETW。
4. **GitHub 远端同步**：等网络可用时 `git push origin main`。
5. **旧数据归档**：1.0 的 `2026-10-31.json`（133847 字节）已被新采集覆盖；
   原始文件备份在 `%TEMP%\ipmon-qa-restore\recovered.json`，可复制到 `%APPDATA%\NetWatcher\archive\` 长期保留。
6. **可选的体验项**：列宽自定义记忆、CSV 导出当前页/全部、托盘图标状态提示、深色模式、
   历史趋势图（`samples` 分钟桶数据已经在文件里，画图即可）。

## 六、如果下一次会话要继续（给 AI/接手者的建议）

1. 先读：`README.md` → `docs/踩坑与决策记录.md` → `docs/开发与维护指南.md` → `CHANGELOG.md`。
2. 环境自检：
   - `cmd /c build.bat` 能过；
   - `tools\qa\verify.ps1 -SkipGui -Seconds 45 -AuditRealData` 应 PASS=27；
   - **任何测试都带绝对 `--datadir` 临时目录**，不要写 `%APPDATA%\NetWatcher`；
   - 启动 GUI 用 `Invoke-CimMethod Win32_Process Create`，不要直接 `Start-Process`（会挂住）；
   - 结束进程按 PID，禁止按进程名批量杀。
3. 已知"不要再踩"的坑：见 `docs/踩坑与决策记录.md`（尤其是 1.1 受限目录、1.2 PowerShell BOM、
   2.1 EStats 不可用、4.1 真实数据事故）。
4. 真机 UI 验收必须截图（`docs/screenshots/` 是参考基线）；管理员窗口无法被非管理员模拟点击。
