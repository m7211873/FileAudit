## 一、技术栈与约束

| 项目 | 说明 |
|---|---|
| 语言 | C# **5.0 语法**（不能用 `$""`、`?.`、表达式体成员等新语法） |
| 框架 | .NET Framework **4.8**，WinForms |
| 编译 | 系统自带 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`（无需 Visual Studio / NuGet） |
| 产物 | 单个 `bin\NetWatcher.exe`（约 109KB；签名后约 110KB） |
| 依赖 | 仅 GAC 里的 `System.Windows.Forms` / `System.Drawing` / `System.Web.Extensions`（`JavaScriptSerializer` 做 JSON） |
| 兼容 | Windows 10/11（x64 / anycpu），不需要管理员即可运行（精确模式可选提权） |
| 编码 | 源码 UTF-8；**PowerShell 脚本必须 UTF-8 with BOM**（PS 5.1 中文解析） |

## 三、启动顺序（重要，别改乱）

```
Main(args)
 ├─ 解析参数（--background/--datadir/--mutex-tag/--selftest/--daemon/--autostart-*/--show）
 ├─ --autostart-on/off：只写/删 HKCU Run 后退出
 ├─ AppConfig.Load(dataDir) → Store.Init(effectiveDir) → GeoIp.Init(...) → startup.log
 ├─ --selftest：跑自检（含 EStats 诊断矩阵）后退出
 ├─ --daemon N：只跑 Monitor N 秒后退出（写 daemon.log）
 ├─ 单实例：Mutex；已存在则 Set 命名事件唤出对方窗口后退出（1.5s 后检查窗口，失败给恢复提示）
 ├─ Monitor.Start()            ← 引擎先于界面启动（UI 挂掉也不影响采集）
 ├─ Application.Run(MainForm(cfg, background, monitor, activateEvent, dataDir))
 └─ finally: monitor.Stop()
```

MainForm 生命周期：
```
构造：BuildUi() → BuildTray() → timer(1s)
OnLoad：SetupSplitter → UpdateHeader → ForceRefresh → timer.Start
        → StartActivationListener（命名事件 → ShowMain）
        → background: 隐藏窗口 + 30 秒内每 3 秒 EnsureTray()
WndProc：TaskbarCreated → EnsureTray()（资源管理器重启后补托盘图标）
关闭窗口：隐藏到托盘（不退出）；托盘菜单「退出」才 ExitApp()
```

## 四、数据模型与聚合规则

```csharp
DayData { date, bytesIn/Out, peak*, sampleCount, bytesPrecise,
          ips: Dictionary<ip, IpAggregate>,
          procs: Dictionary<"进程名|PID|进程启动时间", ProcAgg>,
          samples: List<[minuteUnix, bytesIn, bytesOut]>   // 最多 1440 条（24h 分钟桶） }

IpAggregate { ip, bytesIn/Out, peakIn/OutBps, connectedSeconds,
              sampleCount(出现过的采样次数), sessionCount(真实会话数),
              first/lastSeenUnix, processes(采样出现次数), states, ports,
              city/region/country/isp, bytesPrecise, isNew(仅UI) }

ProcAgg { name, path, pid, processStartUnix, bytesIn/Out, connCount(真实新增连接数),
          first/lastSeenUnix, ips: Dictionary<ip, IpConnAgg> }
```

采样规则（`Monitor.Sample`）：
1. 枚举 TCP（IPv4+IPv6），**丢弃 LISTEN/CLOSED**，其余有远端的状态都记录（`ShowLocalIp=false` 时再过滤内网）。
2. 整机字节差分 → 速率；跨日自动切日并落盘旧日。
3. 精确路径（管理员）：每条 ESTABLISHED 的 IPv4 连接 enable EStats → 读累计 → 差分；失败则本轮降级。
4. 估算路径：整机增量按 **ESTABLISHED 连接数均分**（余数给最后一条，保证合计不丢字节）。
5. 更新 `DayData`（IP/进程聚合、分钟桶、峰值）；`isNew` = 当天首次出现。
6. 构造 `Snapshot`（UI 只读）→ UI 每秒取一次，仅 `LastScan` 变化时重绑表格。
7. 落盘节流：≥15 秒写一次；每 20 次落盘清理一次保留期外文件。

## 五、构建 / 签名 / 安装 / 验收

```powershell
# 1. 编译
cmd /c build.bat                        # → bin\NetWatcher.exe

# 2. 签名（可选，本机自签；必须在编译之后）
cmd /c build-and-sign.bat               # = build.bat + tools\sign\sign.ps1

# 3. 安装（复制到 LocalAppData + 桌面快捷方式 + 开机自启）
powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1

# 4. 验收（headless，不动 GUI；-AuditRealData 会校验真实数据零改动）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\qa\verify.ps1 -SkipGui -Seconds 45 -AuditRealData

# 5. 卸载（默认保留数据；-DeleteData 才删数据）
powershell -NoProfile -ExecutionPolicy Bypass -File uninstall.ps1
```

自检（排查用）：
```powershell
bin\NetWatcher.exe --selftest --datadir "$env:TEMP\nw-selftest"   # 写 selftest.log
bin\NetWatcher.exe --daemon 30 --datadir "$env:TEMP\nw-daemon"    # 写数据 + daemon.log
```

## 六、常见修改场景

### 6.1 加一个统计字段（例如"平均包大小"）

1. `Storage.cs` 的 `IpAggregate` / `ProcAgg` 加 `public long ...` 字段（旧数据缺失自动取默认值，**不要改名/删旧字段**）。
2. `Monitor.Sample` 在聚合处累加。
3. `MainForm` 的表格列定义 + `FillRows` 填充 + 排序 key 映射。
4. 更新 `CHANGELOG.md`。

### 6.2 新增一个标签页

- `MainForm.BuildUi` 里 `tpXxx` + `AddTab("标题", page)`；
- 参考已有页的 TLP 分行方式（**不要**在同容器混用 Dock.Fill 与 Dock.Top）；
- 刷新在 `RebindActiveTab()` / `OnTimerTick` 里按当前选中页处理；
- 截图验收 + 更新用户手册截图（`docs/screenshots/`）。

### 6.3 想让"精确模式"可用（本机 EStats 不可用）

- 先确认：管理员 `--selftest` 的 `EStats 结论:`。若为不可用，代码侧无解。
- 替代方案：ETW `Microsoft-Windows-Kernel-Network`（可覆盖 UDP/QUIC，需要管理员 + 自己写 ETW 消费者，
  C# 无 NuGet 情况下约 500~800 行 P/Invoke，工作量大）。建议单独立项，不要混在 2.x 小版本里。

### 6.4 调整采样间隔

- `Config.AllowedIntervals`（默认 2 秒）+ `SettingsForm` 的下拉项文案；
- 注意 CPU：1 秒档更全但更耗资源；落盘节流固定 15 秒不需要改。

## 七、代码规范（沿用现状）

- C# 5 语法；`delegate {}` 匿名方法而非 lambda（历史代码风格，二者都能编译）。
- 所有可能抛异常的 P/Invoke / 文件 IO 必须 `try/catch` 且有降级，不允许让 UI 线程崩溃；
  引擎线程的异常写入 `monitor.log`。
- 线程安全：`Monitor` 的 `current` 只在 `liveLock` 内改；对 UI 只返回**深拷贝**（`Clone()`）。
- 路径：一律 `Path.Combine`；数据目录用 `AppConfig.EffectiveDataDir()`，**不要硬编码**。
- 中文：界面文案统一简体（国家名有归一化 `NormalizeCn`）。
- 提交信息中文、说明"为什么"；改动涉及行为时同步 `README.md` / `CHANGELOG.md`。
